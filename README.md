# Java Lab Programs

Collection of beginner-friendly Java lab exercises covering basics, arrays, loops, OOP, inheritance, overloading, searching, sorting and related concepts. The repository also includes a few Python practice scripts.

## Run an exercise
```bash
javac Armstrong.java
java Armstrong
```
Use the actual class declared by each source file. Some older files may need independent cleanup.

## Organization
Source files remain in their original locations so existing college assignments and links continue working. Compiled `.class` files already committed are preserved for compatibility, but new compiled outputs are ignored using `.gitignore`.

## Suggested practice
Try `factorial.java`, `fibonacci.java`, `Overload.java`, `TestStack.java`, and `Armstrong.java`. Check each file's main class before running.
